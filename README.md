# COVID-19 wastewater surveillance in Sweden, 2023–2024

This repository contains the data and R code supporting the analyses presented in the manuscript:

**Evaluation of wastewater SARS-CoV-2 surveillance for monitoring COVID-19 trends and early warning in Sweden, 2023–2024**

## Overview

This study evaluates wastewater-based surveillance (WWS) of SARS-CoV-2 in Sweden from July 2023 to December 2024.

Weekly wastewater SARS-CoV-2 levels from 19 wastewater treatment plants (WWTPs) were compared with reported COVID-19 cases to assess temporal correlations at different time lags and the performance of wastewater trends in identifying changes in reported cases.

The relationship between wastewater population coverage and correlation with reported cases was also assessed.

## Repository structure

- `data/` – aggregated data used in the analyses
- `scripts/` – R scripts used to reproduce the analyses and figures
- `results/` – numerical results generated by the analysis scripts
- `figures/` – figures generated by the analysis scripts
- `covid-wastewater-sweden-2023-2024.Rproj` – RStudio project file

## Data

The `data/` directory contains:

- `Supporting_data_s1.xlsx` – aggregated weekly data underlying the analyses presented in the manuscript.

The data contain no individual-level or personally identifiable information.

## Analysis scripts

The `scripts/` directory contains three R scripts:

- `01_cross_correlation_analysis.R` – performs the cross-correlation analyses between wastewater SARS-CoV-2 levels and reported COVID-19 cases, including analyses at different time lags and by periods of increasing and decreasing case numbers. It also assesses the relationship between population coverage and correlation.
- `02_predictive_values_sensitivity_specificity.R` – evaluates the performance of wastewater trends in identifying changes in reported COVID-19 cases, including sensitivity, specificity, positive predictive value (PPV), and negative predictive value (NPV).
- `03_main_figures.R` – generates the main figures presented in the manuscript.

## Reproducing the analyses

1. Clone or download this repository.
2. Open `covid-wastewater-sweden-2023-2024.Rproj` in RStudio.
3. Install the required R packages if necessary.
4. Run the scripts in numerical order.

The scripts use relative file paths and read data from the `data/` directory. Outputs are written to the `results/` and `figures/` directories.

## Data availability

The aggregated data required to reproduce the analyses are provided in the `data/` directory.
